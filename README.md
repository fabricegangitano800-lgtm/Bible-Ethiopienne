# ✝️ The Complete Ethiopian Bible

> The most complete compilation ever attempted of the Ethiopian Orthodox Tewahedo Church canon — 87 books, free for all, in every language.

## About

This project aims to compile **all 81 books of the Ethiopian canon** plus the 6 books of the broader canon — **87 texts total** — into a single, authentic, illustrated volume distributed for free worldwide.

With its 81 books, the Ethiopian Bible is the largest of all Christian Bibles. Yet **no complete Ethiopian Bible has ever existed** — not as a manuscript, not in print, not in any language. This project is a world first.

## Principles

- **Absolute authenticity** — no text invented, altered, or paraphrased
- **Verified sources** — every text sourced and referenced to academic editions
- **Free distribution** — this book is a gift, not a product
- **Every language** — English first, then French, Amharic, Arabic, Spanish, Portuguese, Tigrinya, and more
- **Illustrated** — realistic historical illustrations for each book
- **Seeking EOTC recognition** — built with respect for the Church that preserved these texts
