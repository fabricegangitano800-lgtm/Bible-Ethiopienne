# Contributing to The Complete Ethiopian Bible

## How to contribute

1. **Text recovery** — Help recover and clean source texts from verified academic editions
2. **Translation** — Translate verified English texts into other languages
3. **Review** — Check recovered texts against source material for accuracy
4. **Illustrations** — Create realistic historical illustrations for each book

## Rules

- **NEVER invent or alter any text** — authenticity is absolute
- **ALWAYS cite the source** — edition, translator, year, page numbers
- **ALWAYS use public domain translations** or create original translations
- **NEVER copy copyrighted translations** — create your own from the source
- Flag any uncertainty with `<!-- UNCERTAIN: description -->` comments

## File format

Each book file uses YAML frontmatter + markdown. See any existing file for the template.

## Languages

Priority order: English → French → Amharic → Arabic → Spanish → Portuguese → Tigrinya
